# 学校信息自动化脚本使用示例

## 基本用法

### 1. 使用默认学校（宜宾职业技术学院）
```bash
python browser_automation.py
```

### 2. 指定其他学校
```bash
# 使用完整参数名
python browser_automation.py --school "四川大学"

# 使用简写参数名
python browser_automation.py -s "电子科技大学"

# 其他示例
python browser_automation.py -s "西南交通大学"
python browser_automation.py -s "成都理工大学"
```

### 3. 查看帮助信息
```bash
python browser_automation.py --help
```

## 功能说明

脚本现在支持动态传入学校名称，不再硬编码"宜宾职业技术学院"。

### 主要改进：
1. **动态URL构建**: 根据传入的学校名称自动构建搜索URL
2. **动态内容匹配**: 在页面中查找对应学校的百科链接和信息
3. **命令行参数支持**: 通过 `--school` 或 `-s` 参数指定学校名称
4. **默认值保持**: 如果不指定参数，仍然使用"宜宾职业技术学院"作为默认值

### 注意事项：
- 学校名称需要是准确的全称
- 如果学校名称包含空格或特殊字符，请用引号包围
- 脚本会自动对学校名称进行URL编码
